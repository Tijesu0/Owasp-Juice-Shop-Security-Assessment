## Testing Approach
The assessment followed a manual black-box web application security testing approach.
Testing involved exploring application functionality, examining HTTP communication and evaluating how the application handled different inputs, requests, user actions ad state changes.
Security testing focused on identifying weaknesses in application behavior, security controls and enforcement of expected business rules.
A proxy was used to inspect, manipulate and resend HTTP requests to investigate application responses and verify potential vulnerabilities.
Identified issues were investigated to establish their reproducibility, security impact and appropriate remediation measures.
