# Owasp-Juice-Shop-Security-Assessment

## Project Overview
This project documents a security assessment of OWASP Juice Shop, an intentionally vulnerable web application designed for security testing and education.
The assessment focuses on identifying, understanding, reproducing, and documenting web application security vulnerabilities.

## Assessment Objectives
- Examine the application's attack surface.
- Investigate authentication and authorization mechanisms.
- Investigate information disclosure.
- Documenting vulnerabilities with supporting evidence.
- Recommend appropriate remediation measures.

## Tools
- Burp Suit
- Firefox

## Repository Structure
- methodology/: Testing approach and procedures.
- findings/: Documented security vulnerabilities.
- scan-results/: Automated scanning results, where applicable.
- final-report/: Consolidated assessment report.

## Target Application
OWASP Juice Shop

## Assessment Type
Manual web application security testing.

## Disclaimer
Testing was performed against the intentionally vulnerable OWASP Juice Shop environment.
